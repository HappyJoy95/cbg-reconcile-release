# 盛联门店数据平台 · 发布仓

这里是 **客户端发行仓**：只放安装包 / 更新包、版本信息、变更记录和用户文档。

- **源码不在这里**，也不在这个仓库的历史里。核心源码在私有的开发仓库中。
- 门店电脑的「检查更新 / 自动更新」读的就是这个仓库，不依赖开发仓库。

---

## 我是门店 / 用户

### 下载

去 [Releases](../../releases) 页面，最新一条里有：

| 文件 | 什么时候用 |
|---|---|
| `cbg-reconcile-update.zip.sealed` | **更新**：已经装过的机器，程序自动下这份 |
| `cbg-reconcile-update.zip.sealed.sha256` | 校验下载的文件没损坏（可选） |

> 新店第一次装机的**安装包不放在这个页面**，由实施人员单独发给你。

⚠ **这份更新包是加密的**（`.sealed`），双击打不开是**正常的** ——
程序自己会解，你不用做任何事。这样公开页面上就没人能直接读到源码。

* **解不开**说明这台机器还没有更新包密钥：把 `release.key` 放进安装目录的
  `.secrets\`，或者跟实施人员要一次完整安装包（它带这把钥匙）。
* **手工升级**请用实施人员发的安装包（明文 zip，直接解压覆盖）；
  公开仓这份是给**程序自动更新**用的，人手解不开。

### 装 / 升级

**升级（已有安装）**：控制台「设置 → 检查更新 → 立即更新」是最快的；
程序每天也会自己检查，有新版会在控制台挂提醒 —— 它下载密文、自己解、
自己覆盖，**门店不用碰那个文件**。

**手工升级**：把安装包解压出来的整个 `cbg-reconcile` 文件夹覆盖到安装目录
（默认 `D:\cbg-reconcile`）即可 —— 包里**不带**门店自己的配置和数据，
整个目录直接覆盖是安全的。

详细步骤见 **[门店操作手册](./门店操作手册.md)**。

### 这个程序是干什么的

比对「云商里卖出的、归属本店的串号」有没有都报量给华为，没报的列成差异清单
推邮件 / 企业微信；另有 POS 合规、周度达成、库存盘点等门店日常功能。
安装、启动、排错的完整步骤都在门店操作手册里。

## 版本号

当前版本写在 [`VERSION`](./VERSION) 里，客户端读它判断有没有新版。
发版号格式是 `yy.mmdd.hhmmss`（如 `26.0929.191128`）——
数字定宽，按点拆开比大小即可。

每一条 Release 的正文 = 那一版的变更说明，同时汇总在 [CHANGELOG.md](./CHANGELOG.md)。

## 给实施 / 维护人员

- **发版**：在开发仓库里打包，然后用 `tools/publish_release.sh` 推到这个仓库。
- **这个仓库里不许出现**：`.py` 源码、采集实现、业务逻辑、
  `.secrets/`、凭据、密钥、门店配置。发布脚本里有反查断言拦着。
- **更新包是加密的**（`.zip.sealed`，路线 A，2026-10-02）——
  公开仓上连安装包内容都读不到；钥匙 `.secrets/release.key` 私发，
  永远不进这个仓库（发布脚本 `BAN_NAMES` + gitignore 两道挡着）。
- 安装包（含中台邮箱授权码、邮件附件加密密钥的那份）**只私发**，不进这里。

变更记录见 [CHANGELOG.md](./CHANGELOG.md)。
